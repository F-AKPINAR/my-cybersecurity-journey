# 📚 Resources and Tools

Tools and resources I met and found useful on my cybersecurity journey.

## 🧰 Tools

| Tool | What it's for |
|------|---------------|
| **Nmap** | Network and port scanning, service/version detection |
| **Wireshark** | Network traffic (packet) analysis — graphical interface |
| **tcpdump / tshark** | Capturing/analyzing packets from the command line |
| **Metasploit Framework** | Vulnerability exploitation and penetration testing |
| **Kali Linux** | A Linux distribution that ships with pentest tools |
| **telnet / ssh** | Connecting to a remote machine (telnet is unencrypted, ssh is encrypted) |

## 🔐 Core Concepts (quick recap)

- **CIA Triad:** Confidentiality · Integrity · Availability
- **Encoding ≠ Encryption ≠ Hashing**
- **Bind shell vs Reverse shell**
- **Cyber Kill Chain** — the 7 stages of an attack
